# 공감네트웍스 META 운영 제안서

## GitHub Pages 배포
1. 이 폴더 안의 `index.html`, `company_01.jpg`~`company_08.jpg`, `creative_1.png`~`creative_3.png`을 GitHub 저장소 최상위에 업로드합니다.
2. 저장소 `Settings > Pages`에서 `Deploy from a branch` → `main` / `/ (root)` → Save를 선택합니다.
3. 생성된 주소에서 페이지를 확인합니다.

## 조작
- 좌우 화살표 또는 화면 양옆 버튼으로 이동, 모바일 좌우 스와이프, 목차 버튼으로 슬라이드 선택.
- 브라우저 인쇄를 사용하면 슬라이드별 PDF 저장 가능(배경 그래픽 인쇄 활성화 권장).

## 외부 발송 전 수정할 항목
- **중요:** 요청 표지는 공감네트웍스이나 제공된 회사소개서는 링크프라이스입니다. 1~8페이지 원본을 그대로 수록했으므로 사용 주체 및 허락 여부를 확인하세요.
- 가상 운영 예시와 대시보드 예시를 실적 사례로 오인하지 않도록 표기 유지. 실운영 레퍼런스는 증빙된 자료로 교체.
- 수수료 및 월 광고 예산, 실제 객단가, 마진, 소재 제작 범위 확정.
- Meta Marketing API + Claude API 연계는 기능 제안이며 실제 구축·권한·비용 확인 필요.
